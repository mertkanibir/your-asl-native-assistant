# Semester 3 poster

- [Poster PDF](yana-semester-3-poster.pdf)
- [PNG preview](yana-semester-3-poster.png)

The team supplied the one-slide PowerPoint poster `YANA Sem 3 Poster.pptx` from the open Google Slides document. The PDF preserves its 48 × 36 inch layout and original visual content, including the five authors, university identity, diagrams, demonstration images, research claims, and references.

The PDF was exported locally with LibreOffice after the Safari export connection became unavailable. The preview was rendered from that PDF with Poppler. Both are static research artifacts. The original presentation, speaker notes, comments, and embedded project environment files are not included in these exports.

Verification confirmed one PDF page, no annotations, no embedded file attachments, and no speaker-note text in the page extraction. The rendered poster was visually checked at full-poster scale. The source’s built-in interface styling, wording, and video stills remain intact.

The poster describes Semester 3 work beyond the earlier code snapshot in this repository. Its CNN, Wan 2.2, OpenPose, and generated signing-video workflow should not be inferred from the checked-in landmark prototype. See the root [README](../../README.md) for the implemented scope and missing runtime assets.
